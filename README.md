
# Bookstore Intelligence Mission

This project uses Python web scraping to collect and analyze competitor book data from Books to Scrape, a sandbox website designed for web-scraping practice.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Project Tasks
- Scraped book titles, prices, ratings and availability
- Converted star ratings from words to numeric values
- Scraped multiple pages using reusable logic
- Created and cleaned a Pandas DataFrame
- Exported the dataset as `competitor_books.csv`
- Analyzed prices, ratings and availability
- Completed the CEO £100 optimization challenge
- Created a visualization of book-rating distribution

## Dataset
The dataset contains:
- Title
- Price
- Rating
- Availability
- Product URL

## Business Analysis
The scraped data was used to answer business intelligence questions and identify highly rated, competitively priced books that could be prioritized by a competing bookstore.

## CEO £100 Challenge
A budget optimization approach was used to select books that maximize the total star-rating score without exceeding a £100 budget.

## Data Source
Books to Scrape — a sandbox website designed for web-scraping practice.
